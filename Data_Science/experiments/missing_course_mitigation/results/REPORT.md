# MissingCourseMitigation on frozen optimized XGBoost

Simulated missing-course corruption on original AIS histories. No model retraining or forced degradation. Negative paired MAE change favors mitigation. Poly and ordinary XGBoost remain unchanged.

Course is atan2(east velocity, north velocity), converted to degrees and wrapped into [0,360). It uses the same five-minute causal position fit and checks as Missing Speed. Extra fixed settings: at least one knot for fitted and segment motion, 30 m net displacement, and no segment direction more than 20 degrees from the fitted direction. These are provisional settings fixed before evaluation. Stopped or ambiguous tracks retain missing course. Existing 0-degree courses remain valid north.

The existing C guard runs first. Only course sine/cosine, course dispersion, recent turn, and velocity disagreement may change. Observed missing-course fraction, all speed/position features, clocks and guard diagnostics remain intact. Model inputs never contain hidden originals, attack flags, audit records or crossing labels.

These are the largest regressions relative to the attacked feed. Comparing them with clean C also exposes pre-existing model errors: restoring a useful feature can restore an existing prediction mistake. Removing information can occasionally improve a flawed model. The actual harmed cases remain in all metrics; these examples do not excuse their regressions.

Direction from a trailing fit is recent average course, not independently verified instantaneous course over ground; bow heading is not reconstructed. Coherent GPS errors or unobserved turns can still defeat it. The selected cohort's clean missingness and control changes are recorded in the table; clean identity alone does not validate reconstruction on naturally missing records. Model trees and imputer are unchanged; existing missing indicators generated by the imputer follow the effective numeric features. Original missing-course fraction is preserved, but uncertainty is not calibrated for this new path.

April was inspected previously and is a follow-up cohort, not a pristine holdout. Stress rates are proposed simulated settings, not measured real-world failure rates. Arrival means the analytical crossing, not docking. Full P95 and per-decision diagnostics are saved as locally ignored CSVs.

Missing Speed's old prediction file is read-only during regression checking. Its full saved cohort and reconstruction counts must match before this experiment is allowed to run. See speed_regression.json.
